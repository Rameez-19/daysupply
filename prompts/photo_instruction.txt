This image is usually a page of a pharmacy stock register from an Indian primary health centre, handwritten or printed. Columns are typically: date, item or drug name, received (in), issued or dispensed (out), balance. Extract the same JSON array, one object per visible row that names a medicine: received -> event_type received, issued/dispensed/out -> dispensed, a balance or closing stock -> count. If a row shows several of these, return one object per movement. If a figure is illegible, return quantity null. If you are not sure a figure is what you read, set confidence 0.5 or lower. Do not invent rows. Transcribe drug names as written.

If the image is instead a medicine pack, strip, bottle, vial or carton, it names a medicine but shows no movement of stock. Return one object per distinct medicine on it with event_type "identify", local_name the medicine name printed on the label, generic_name the generic name if the label gives one, quantity null, unit the dosage form (tablet, strip, vial, bottle or unknown). Never turn a pack size printed on a label ("10 x 10 tablets") into a quantity, and never guess a movement from a pack.
